# LVNG-X Game Space (v5)

Android Gaming Hub & Overlay System built with Kotlin, Jetpack Compose, and Shizuku API, modeled 100% after Zayon style with Crimson Red theme and zero emojis.

## Features
- Crimson Red Zayon Style Theme
- Floating Control Panel with Real-time FPS, RAM & CPU monitoring
- Performance Booster Modes (Eco, Balanced, Ultra)
- Virtual Crosshair & Shizuku Macro System with Hold-to-Click, Draggable & Lockable floating button
- Touch Optimize & Activation Center
